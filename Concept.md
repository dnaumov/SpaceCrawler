# Cell Builder

## Concept

Cell Builder is a mobile-first game in which players assemble cells and microorganisms from modular biological components, then compete against procedurally generated organisms in automated simulation matches.

## Core loop

1. Build a cell from available organelles on a 4 x 4 grid.
2. Enter a simulation match against AI-designed species.
3. Collect food, survive environmental hazards, and duplicate.
4. Review the result and improve the organism.
5. Unlock stronger organelles and progress into new environments.

## Product goals

- Make organism design tactically meaningful and easy to use on mobile devices.
- Let emergent behavior arise from simple biological rules and organelle combinations.
- Support rapid balancing through a deterministic simulation that can run without Godot.
- Reward experimentation rather than a single optimal organism design.
